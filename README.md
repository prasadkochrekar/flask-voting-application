# Flask Voting Application

## Project Description

This is a simple Voting Application built using Python and Flask. The application allows users to cast votes for candidates, view the current voting results, and reset all votes.

The project also demonstrates a Git version control workflow using separate `dev` and `main` branches.

---

## Features

- Basic Flask application
- Home endpoint
- Health check endpoint
- Cast votes for candidates
- View voting results in JSON format
- Reset all votes
- Git branching using `dev` and `main`
- Version-controlled development using Git and GitHub
